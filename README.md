
# بورتفوليو سيف طاهر - نحّات وفنان تشكيلي

موقع بورتفوليو احترافي وسهل التعديل لعرض الأعمال النحتية والفنية.

## 🎨 الميزات الرئيسية

- ✨ **تصميم حديث وجذاب** بالألوان الأحمر والأصفر والأبيض
- 📱 **متجاوب تماماً** مع جميع أحجام الشاشات (موبايل، تابلت، ديسكتوب)
- 🖼️ **معرض تفاعلي** مع إمكانية عرض تفاصيل كل عمل
- 🔍 **تصفية الأعمال** حسب الفئات المختلفة
- 🎯 **سهل التعديل** - كل البيانات في ملف واحد
- 📊 **صفحة تعريف احترافية** مع معلومات التواصل
- 🚀 **سرعة تحميل عالية** وأداء ممتازة

## 📂 هيكل الملفات

```
sculptor-portfolio/
├── index.html          # الصفحة الرئيسية
├── styles.css          # أنماط CSS (الألوان والتصميم)
├── script.js           # وظائف JavaScript
├── data.js             # بيانات الأعمال (سهل التعديل)
├── README.md           # هذا الملف
└── assets/             # مجلد الصور
    ├── profile.jpg     # صورة البروفايل
    └── works/          # صور الأعمال
        ├── work1.jpg
        ├── work2.jpg
        └── ...
```

## 🚀 البدء السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/seiftaher2005/sculptor-portfolio.git
cd sculptor-portfolio
```

### 2. إضافة الصور
- ضع صورتك الشخصية في `assets/profile.jpg`
- ضع صور أعمالك في مجلد `assets/works/`

### 3. تحديث البيانات
قم بتعديل ملف `data.js` وأضف أعمالك الخاصة:

```javascript
{
    id: 1,
    title: "عنوان العمل",
    category: "sculpture",  // أو "mixed" أو "installation"
    year: "2024",
    image: "assets/works/work1.jpg",
    description: "وصف قصير للعمل",
    techniques: "الخامات المستخدمة",
    details: "وصف تفصيلي للعمل"
}
```

### 4. تحديث معلومات التواصل
عدّل معلومات التواصل في قسم Contact في `index.html`:
- البريد الإلكتروني
- الهاتف
- روابط وسائل التواصل الاجتماعي

## 🎨 تخصيص الألوان والأنماط

جميع الألوان والأنماط معرّفة في ملف `styles.css` في بداية الملف:

```css
:root {
    --primary-red: #E63946;      /* الأحمر الأساسي */
    --primary-yellow: #FFD60A;   /* الأصفر الأساسي */
    --primary-white: #F8F9FA;    /* الأبيض الأساسي */
    /* ... باقي الألوان */
}
```

يمكنك تغيير أي لون ببساطة وسيؤثر على الموقع كله.

## 📝 تعديل الأقسام الرئيسية

### قسم البطل (Hero Section)
في `index.html`، ابحث عن `<section id="home" class="hero">` وعدّل النصوص والصور.

### قسم من أنا (About Section)
في `index.html`، ابحث عن `<section id="about" class="about">` وحدّث المعلومات الشخصية.

### الأعمال (Portfolio)
في `data.js`، عدّل مصفوفة `portfolioData` وأضف أعمالك.

### التواصل (Contact)
��ي `index.html`، عدّل بيانات التواصل في `<section id="contact" class="contact">`.

## 🔧 الوظائف المتقدمة

## 🌐 نشر الموقع

### استخدام GitHub Pages
1. اذهب إلى إعدادات المستودع
2. انتقل إلى "Pages"
3. اختر "Deploy from a branch"
4. اختر الفرع "main"
5. سيكون الموقع متاحاً على `https://seiftaher2005.github.io/sculptor-portfolio`

### استخدام خدمات أخرى
يمكن نشر الموقع على:
- Netlify
- Vercel
- Firebase
- أي استضافة ويب أخرى

## 🎯 نصائح للاستخدام الأمثل

1. **جودة الصور**: استخدم صور عالية الجودة وحجم ملائم
2. **الوصف الجيد**: اكتب وصفاً تفصيلياً لكل عمل
3. **التحديث المنتظم**: أضف أعمالك الجديدة بانتظام
4. **وسائل التواصل**: تأكد من تحديث معلومات التواصل
5. **اختبار الأجهزة**: اختبر الموقع على أجهزة مختلفة

## 🐛 حل المشاكل الشائعة

### الصور لا تظهر
- تأكد من أن مسار الصورة صحيح
- تأكد من أن ملفات الصور موجودة في المجلد
- الملف سيظهر صورة بديلة تلقائياً

### النصوص لا تظهر بشكل صحيح
- تأكد من ترميز الملفات UTF-8
- تحقق من الفاصلة والعلامات في JSON

### الموقع لا يستجيب
- امسح ذاكرة التخزين المؤقتة للمتصفح
- تحقق من وحدة التحكم (Console) للأخطاء
